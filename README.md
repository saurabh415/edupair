# EduPair - Skill Swap Learning Network

A peer-to-peer learning network where students teach what they know and learn what they don't. Earn credits to unlock more knowledge.

## Features

- Create and manage your profile with skills and learning interests
- Offer teaching sessions in your areas of expertise
- Join learning sessions from other students
- Earn and spend credits for teaching and learning
- Track your credit balance and transaction history

## Tech Stack

- React
- Vite
- Chakra UI
- React Router
- Local Storage for data persistence

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) to view it in your browser

## Project Structure

- `src/components/` - Reusable UI components
- `src/pages/` - Page components
- `src/context/` - React context for state management
- `src/utils/` - Utility functions
- `src/assets/` - Static assets

## How It Works

1. Create a profile and list your skills and learning interests
2. Offer teaching sessions in your areas of expertise
3. Earn credits for each completed teaching session
4. Use your credits to join learning sessions from other students
5. Track your progress and credit balance
